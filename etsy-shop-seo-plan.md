## Important: Etsy tags are per listing

Etsy does not have one global set of 13 tags for an entire shop. Tags are attached to individual listings. The sections below give each of the 48 visible listings a separate starter set of 13 relevance-focused tags. Each suggested tag is 20 characters or fewer; tags are separated with ` | ` so you can copy them one at a time.

Etsy's guidance is to use all 13 tags, favor natural multi-word phrases, avoid duplicate tags within a listing, and keep titles short and easy to scan. These are relevance-first suggestions, not a promise of high search volume or sales. See Etsy's [title and tag guidance](https://www.etsy.com/seller-handbook/article/1347574487014) and [search guidance](https://www.etsy.com/seller-handbook/article/how-etsy-search-works/375461474487).
